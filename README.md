# AmaazLoader Website

Official landing page source for AmaazLoader.

## GitHub Pages

1. Open **Settings → Pages**.
2. Choose **Deploy from a branch**.
3. Select `main` and `/ (root)`.
4. Save.

Expected URL: `https://amaazbots.github.io/AmaazLoader-Website/`

## Download button

When the v1.0.0 installer is uploaded to GitHub Releases, replace `const DOWNLOAD_URL = "#";` inside `script.js` with the installer URL.
