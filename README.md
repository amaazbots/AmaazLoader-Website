# AmaazLoader Website

Official landing page source for AmaazLoader.

## GitHub Pages

1. Open **Settings → Pages**.
2. Choose **Deploy from a branch**.
3. Select `main` and `/ (root)`.
4. Save.

Expected URL: `https://amaazbots.github.io/AmaazLoader-Website/`

## Download button

The download button currently points to the public AmaazLoader v1.2.1 installer on GitHub Releases.
