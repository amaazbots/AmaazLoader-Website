# AmaazLoader v1.0.0

The first public release of AmaazLoader.

AmaazLoader is a modern Windows utility designed to make signing and installing IPA files on iPhone and iPad simple.

## Highlights

- Automatic IPA signing using your own Apple Account
- Direct USB installation to iPhone and iPad
- Apple Two-Factor Authentication support
- Automatic connected-device detection
- Apple Developer team detection
- Real-time authentication, signing and installation progress
- Built-in IPA metadata detection
- Portable signing backend
- Bundled device communication tools
- Modern Windows interface
- Native Windows installer

## How it works

1. Connect your iPhone or iPad by USB.
2. Select an IPA.
3. Connect your Apple Account.
4. Complete Apple verification if requested.
5. AmaazLoader signs the app and installs it directly to the device.

## Privacy

AmaazLoader does not intentionally save your Apple Account password or two-factor authentication code. Credentials are supplied when required during authentication/signing.

## Requirements

- Windows 10 or Windows 11
- 64-bit Windows
- iPhone or iPad connected by USB
- Apple Account
- Internet connection for Apple authentication and signing services
